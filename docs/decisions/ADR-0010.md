# ADR-0010 — Temporizadores de partida (valores iniciales, sin implementar)

Fecha: 18/10/2026. Estado: documentado en CODEX-005G-C3A; ningún temporizador está activo.

## Valores iniciales configurables
| Etapa | Duración inicial |
|---|---|
| Cara o cruz | 15 s |
| Decisión de subasta | 25 s |
| Organización del equipo | 75 s |
| Selección de estrategia | 30 s |

## Decisiones
- En el prototipo local no existe temporizador obligatorio: un vencimiento podría romper una partida hot-seat, donde las personas se pasan el dispositivo. Cuando se implemente, deberá poder desactivarse en modo local.
- Los valores se tratarán como configuración, no como constantes de reglas; este ADR no añade código para evitar abstracciones sin uso.
- Al vencer cada etapa se aplicará una acción por defecto explícita y registrada (a definir al implementarlos): pasar en la subasta, confirmar el orden actual del once, elegir `NEUTRAL` en la estrategia. Nunca se resolverá un vencimiento con una compra obligatoria silenciosa.

## Futuro online
Los vencimientos serán **autoritativos en el servidor**: el servidor guardará la marca de inicio y la fecha límite de cada etapa, resolverá el vencimiento una sola vez (idempotente) y transmitirá el resultado. El reloj de React solo mostrará una cuenta regresiva informativa y nunca decidirá un resultado, una puja ni una elección de estrategia.
