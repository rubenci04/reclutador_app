# ADR-0006 — Identidad comercial y modalidades verificables

Fecha: 17/10/2026. Estado: aceptada.

## Contexto

El producto se presenta como El Reclutador y necesita futuros duelos por nacionalidad, trayectoria, período y competición sin mezclar hechos históricos con las evaluaciones editoriales del catálogo.

## Decisión

- `PRODUCT.name` centraliza la marca visible como **El Reclutador**. Se preservan `draft-legends.draft-v1`, `catalog_v1`, `plr_*`, rutas y carpetas para que los borradores compatibles sigan restaurándose sin migración.
- El `Player` canónico continúa siendo la única identidad. `PlayerMetadata` es un índice aditivo por `playerId`, con trayectoria, selección, apariciones, proveedor, identificador externo y estado de verificación.
- Una regla de nacionalidad usa exclusivamente `Player.nationality`. Una regla de liga exige una carrera verificada. Una edición exige competición y año coincidentes; década o año de referencia no crean una aparición histórica.
- El filtro puro devuelve jugadores y diagnóstico. Exige 1 ARQ, 4 DEF, 3 MED, 3 DEL, un once de hasta 100M y compatibilidad con el mismo generador CPU. No añade rellenos ni relaja la economía.
- Solo Global se activa en la interfaz actual. Las demás modalidades se muestran como fundación pendiente hasta contar con metadatos revisados y una integración de partida que conserve las restricciones durante todo el flujo.
- Las importaciones futuras serán offline, versionadas y revisadas editorialmente. No habrá API comercial en runtime ni secretos en navegador. La decisión de fuente se hará por competencia/temporada y contrato de reutilización, no por una promesa genérica de cobertura.

## Consecuencias

La marca cambia sin pérdida de borradores. La futura carga de datos puede ser parcial y segura: `unknown` no se interpreta como elegibilidad. Las modalidades no se anuncian como jugables hasta que la evidencia y el once económico lo permitan. El diagnóstico del simulador separa observación de una decisión de diseño: las probabilidades actuales no se cambian en esta ADR.
