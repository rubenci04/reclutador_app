# ADR-0007 — Duelo de Reclutadores y garantías de subasta

Fecha: 17/10/2026. Estado: aceptada.

## Decisión

Duelo de Reclutadores es el modo local principal. Una partida parte de una semilla explícita y construye once parejas de 4-3-3: 1 ARQ, 4 DEF, 3 MED y 3 DEL; cada pareja contiene dos futbolistas únicos de la misma posición. El constructor realiza como máximo 48 intentos deterministas y solo acepta un conjunto para el que existe una asignación de precio base que deja ambos presupuestos dentro de 100M.

El cara o cruz se calcula al crear la partida, se almacena en el registro y solamente se revela después de la animación. Ese resultado define la primera prioridad; la prioridad alterna por ronda. En cada subasta el primer jugador es el premio y el segundo es la alternativa. La apertura puede ofertar exactamente el precio base o pasar. Las contraofertas aumentan por lo menos 1M; quien pasa no puede reingresar. Una puja gana el primer jugador y el rival recibe el alternativo por su precio base. Sin puja, se intenta la dirección de la prioridad y luego la inversa, siempre que sea viable.

Antes de aceptar una oferta o adjudicar, el motor puro calcula si cada lado puede pagar lo ya comprometido, la adjudicación actual y alguna asignación de todos los pares restantes. La búsqueda de dos direcciones por cada par está acotada a 2¹¹ estados de decisión. La oferta máxima segura es la mayor entera que mantiene ese invariante. No se cambian precios, no hay importes fraccionarios ni presupuestos negativos.

El estado usa fases explícitas LOBBY, COIN_TOSS, REVEAL_PAIR, BIDDING, ROUND_RESULT, NEXT_ROUND, TEAMS_COMPLETED, SIMULATING y MATCH_RESULT. Guarda semilla, pares, prioridad, ofertas, pases, adjudicaciones, saldos, lineups y resultado. React coordina la interfaz; no es la autoridad de las reglas. El partido se delega al simulador ya existente una sola vez tras validar ambos onces.

## Consecuencias

El motor es importable por un futuro servidor autoritativo y recibe un catálogo elegible, por lo que una modalidad temática podrá filtrar antes de sortear sin insertar jugadores externos. Esta entrega no crea modo online, salas, autenticación ni CPU pujadora. Draft Libre permanece como alternativa local.
