# ADR-0009 — CPU estratégica, recursos visuales y expansión argentina

Aceptada, 2026-10-17, CODEX-005C.

## CPU y economía

El checkout 42f56cb no contenía CPU pujadora. El comportamiento de +1M reportado no se reproduce en esa revisión; se incorpora una opción Contra CPU y se conserva hot-seat.

La valoración privada es fija durante cada ronda. Usa semilla, perfil, carta, atributos de rol (defensa para ARQ/DEF, ataque para DEL, ataque/mental para MED), físico/mental, cupos pendientes y dinero. No recibe la oferta rival ni las rondas futuras. Una preferencia con semilla varía entre -2.5 y +2.5M. Primas CONSERVATIVE/BALANCED/AGGRESSIVE: -1.8/+0.2/+2.2M; factores de gasto por puesto: 0.82/1/1.2. Se reserva el mínimo público para los puestos restantes usando el catálogo publicado y excluyendo fichados. El coste de oportunidad limita el gasto por puesto. El mínimo entre estos límites es el máximo privado.

El decisor recibe la oferta para decidir si aún vale la pena, nunca para aumentar ese máximo. Incrementos posibles: 1M para conservadora, 1–2M equilibrada y 1–3M agresiva, limitados por valoración y máximo técnico. Sólo el máximo técnico consulta el conjunto futuro para garantizar viabilidad. Registro técnico separado con perfil, acción, motivo y máximo privado; la UI no muestra ese máximo.

Se mantienen 22 cartas. Tras dos pases, una asignación por prioridad o viabilidad es obligatoria y se etiqueta como tal; no se registra una oferta ficticia. Se distingue `voluntary_bid`, `double_pass_priority` y `forced_viability`. Ampliar el conjunto y permitir cartas desiertas requiere otra ADR, nuevos criterios de cierre y nueva generación económica.

Se corrige un fallo previo: el cierre no puede exigir que el gasto de subastas sea igual al precio base de catálogo. Debe admitir sobreprecios legales y validar cupos, unicidad y gasto hasta 100M.

## Identidad visual

flag-icons 7.5.0 se empaqueta localmente, MIT, con copia de licencia. Mapeo FIFA explícito: ENG/gb-eng, SCO/gb-sct, WAL/gb-wls; no se usa la bandera británica indistintamente. Países históricos aún no admitidos requieren una decisión editorial independiente y mientras tanto usan fallback; no se infiere un sucesor moderno. La bandera representa la asociación del registro, no residencia ni lugar de nacimiento.

Manifiesto fotográfico separado del deporte, aprobación explícita, archivos locales y fallback por ausencia/error. Piloto de una foto verificada, sin completar artificialmente diez. No se incorporan escudos oficiales; se usan monogramas propios y nombre del club derivado del club_tag. El soporte de escudos exige licencia y restricciones de marca.

## Expansión argentina

Primera expansión comercial: 200 nuevas identidades vinculadas a clubes argentinos, incluyendo extranjeros. Cuatro lotes ARG-B01..04, 50 cada uno, matriz por lote 6/16/15/13 y total 24/64/60/52. No se generan jugadores ni ratings en este encargo.

`plr_151..500` ya están reservados. Se reserva `arg_001..200` en una colección independiente `argentina_collection_v1`; no se pasan esos IDs a validadores catalog_v1. Una futura integración requerirá un ensamblador versionado y adaptación explícita de validadores/simulador, conservando los IDs originales. Se exige identidad externa canónica y contraste de alias contra existentes; un jugador actual con carrera argentina reutiliza su plr_* y sólo agrega trayectoria.

EARLY_ACCESS_250 pasa a priorizar 150 actuales + primeros 100 nuevos argentinos verificados. Colección argentina completa daría 350 identidades jugables, sin declarar FULL_CATALOG_500 completo. El viejo contrato global 300/200 y sus rangos se preservan como plan pendiente, subordinado comercialmente a esta expansión; cambiar esa distribución requerirá decisión futura.
