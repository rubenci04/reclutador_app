# Registro CODEX-005A

Fecha: 17/10/2026.

Se incorporó Duelo de Reclutadores como modo local principal sin retirar Draft Libre ni el partido contra CPU existente. La única diferencia de interpretación respecto de la planificación anterior es que el navegador integrado no pudo validar Vite: devolvió `net::ERR_CONNECTION_REFUSED` para `127.0.0.1:5173`; el informe QA lo deja como no ejecutado y aporta la guía manual.

La regla local no constituye una implementación online: el resultado del cara o cruz se registra en el motor, pero la futura autoridad oficial queda reservada al servidor. No se modificaron catálogo, precios, ratings, economía ni se añadieron servicios externos.
