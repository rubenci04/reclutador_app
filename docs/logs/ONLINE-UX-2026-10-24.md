- Primera ejecución específica detectó un mock de navigator.share incompatible con jsdom; corregido con propiedad configurable restaurada tras cada prueba. OnlinePage: 16/16 aprobadas. Primera suite completa sin límite de procesos: timeout de 20 s en freeKicks, interrumpida y repetida con concurrencia limitada. Con dos workers: 1.411/1.412 aprobadas; único fallo por expectativa histórica de tres descartes online, actualizada al pedido actual. Esa ejecución aprobó los tres archivos online solicitados y la prueba de tiros libres que había agotado tiempo.
- Resultados finales: `npm run typecheck`, `npm run lint` y `npm run build` terminaron con código 0. Lint conserva tres advertencias anteriores de Fast Refresh en DribblePanel.tsx; build conserva el aviso de debugName de codeSplitting en vite.config.ts, sin chunks mayores de 500 kB.
- Suite completa final: `npm test -- --maxWorkers=4`, código 0, **1.412 pruebas en 132 archivos**, 154,17 s. Incluye OnlinePage.test.tsx, onlineDuel.flow.test.tsx, onlineDuel.database.test.ts y la regresión DISCARD-005 corregida. La concurrencia se limita sólo en el comando, sin alterar configuración ni tiempos de las pruebas.

Las pruebas usan jsdom, adaptadores y PostgreSQL embebido; no hay sesión móvil ni backend remoto configurados para esa validación. Las comprobaciones DOM no acreditan layout ni audio real.
